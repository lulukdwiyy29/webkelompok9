Mata Pelajaran: Informatika

Mengenal Struktur Web

Website ini dibuat dengan bahasa HTML dan CSS. HTML digunakan untuk menulis struktur isi seperti teks dan tabel, sedangkan CSS untuk membuat tampilan lebih menarik dan berwarna.


Tambahan Materi: CSS & JavaScript

CSS (Cascading Style Sheets) bekerja seperti "baju" untuk website kita. Tanpa CSS, web hanya akan berisi tulisan hitam putih yang membosankan. Sementara itu, JavaScript adalah otak dari website yang membuatnya interaktif.


Contoh Kode HTML yang Digunakan:

Berikut adalah cuplikan kode asli yang kami gunakan untuk membuat tampilan judul Bahasa Indonesia di bawah:

<h2>Bahasa Indonesia</h2> <p>Kokurikuler siswa belajar lebih efesien.</p>

(Kode di atas adalah contoh elemen dasar HTML)

Bahasa Indonesia: Teks Eksposisi

Sekolah di Era Digital: Mengapa Harus “Smart”?

Dalam beberapa tahun terakhir, perubahan teknologi berlangsung sangat cepat. Proses belajar mengajar tidak lagi terbatas pada buku cetak dan papan tulis. Sekolah membutuhkan sistem yang mampu menyesuaikan diri dengan kebutuhan generasi digital—siswa yang tumbuh dengan gawai, internet, dan aplikasi.


Smart school hadir sebagai solusi. Istilah ini merujuk pada sekolah yang menerapkan teknologi untuk meningkatkan efektivitas pembelajaran, administrasi, dan layanan siswa secara keseluruhan.

Penerapan Smart School: Studi Kasus dan Contoh Nyata

Berbagai sekolah di Indonesia sudah mulai mengadopsi sistem smart school. Beberapa penerapannya meliputi:

  • Kelas Berbasis Teknologi: Guru menggunakan perangkat presentasi digital, video edukasi, dan aplikasi kuis interaktif untuk membuat suasana belajar lebih hidup.
  • Sistem Administrasi Online: Presensi dan nilai dapat diakses secara real-time.

Kami menganalisis tiga topik utama yang berkaitan dengan kehidupan sehari-hari:

1. Lingkungan

Pemanasan global semakin terasa. Perubahan iklim menyebabkan cuaca tidak menentu. Solusinya adalah reboisasi dan pengurangan penggunaan plastik sekali pakai di lingkungan sekolah.
